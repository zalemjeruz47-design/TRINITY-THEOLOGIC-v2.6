
TRINITY LOGOS THEOLOGICA V2.6 - Propósito

Trinity Logos Theologica es un proyecto para unir Fe - Razón - Voz, para la gloria de Dios solo: SOLI DEO GLORIA.

Se sostiene en 3 pilares:
- LOGOS: La Palabra, la Verdad, la razón ordenada
- SOPHIA: La Sabiduría, el discernimiento
- PNEUMA: El Espíritu, la vida y la presencia

Y se vive en 5 dimensiones:
- ISCHYS - Fuerza
- NEPHESH - Alma
- NOUS - Mente
- KARDIA - Corazón
- KERYX - La Heraldo, la voz

Bajo un solo llamado: LOGOS ORCHESTRATOR

Fe - Razón - Voz
SOLI DEO GLORIA
